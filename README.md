# Crossy Pets — как запустить игру на Mac

Это простая браузерная игра в духе Crossy Road. Никаких игровых движков, серверов и дополнительных библиотек не требуется.

## Самый простой запуск

1. Распакуй архив `crossy_pets.zip`.
2. Открой папку `crossy_pets`.
3. Дважды кликни по файлу `index.html`.
4. Он откроется в Safari или другом браузере.
5. Играй.

Управление:
- клик мышкой по игровому полю — шаг вперед;
- `↑` или `Space` — вперед;
- `←` и `→` — в стороны;
- `↓` — назад;
- `R` — перезапуск;
- кнопки `Котик` и `Лягушка` переключают персонажа.

## Где находится весь код

Почти вся игра находится в одном файле:

`index.html`

Внутри него есть три части:

1. `<style> ... </style>` — внешний вид страницы.
2. `<canvas id="game">` — место, где рисуется игра.
3. `<script> ... </script>` — вся игровая логика.

## Чем редактировать код

Самый удобный вариант — Visual Studio Code (VS Code).

После установки:
1. Запусти VS Code.
2. File → Open Folder.
3. Выбери папку `crossy_pets`.
4. Открой `index.html`.
5. Меняй код.
6. Нажми `Cmd + S`.
7. Вернись в браузер и обнови страницу через `Cmd + R`.

Можно использовать и обычный TextEdit, но VS Code намного удобнее для кода.

## Если игра не запускается

### Вариант 1. Открывается текст, а не игра

Убедись, что файл называется именно:

`index.html`

а не:

`index.html.txt`

### Вариант 2. Белый экран или игра сломалась после изменений

В браузере открой инструменты разработчика:

Safari:
- Safari → Settings → Advanced;
- включи отображение функций для веб-разработчиков;
- затем Develop → Show JavaScript Console.

Chrome:
- нажми `Option + Command + J`.

Красная строка в консоли обычно показывает ошибку и номер строки.

### Вариант 3. Хочешь вернуть рабочую версию

Просто заново распакуй исходный архив. В нем лежит первоначальная рабочая версия.

## Как устроена игра

Основные переменные:

`player`
Хранит положение персонажа.

`character`
Определяет, кто выбран: котик или лягушка.

`highestY`
Текущий счет.

`rowType(worldY)`
Определяет тип очередного ряда: трава, дорога или вода.

`carPositions(...)`
Рассчитывает движение машин.

`logPositions(...)`
Рассчитывает движение бревен.

`move(dx, dy)`
Передвигает игрока.

`checkCollision(...)`
Проверяет столкновение с машиной или падение в воду.

`loop(...)`
Главный игровой цикл. Браузер вызывает его снова и снова, чтобы игра постоянно обновлялась.

## Как внести первые изменения

### Изменить скорость машин

Найди:

`function rowSpeed(worldY)`

и число:

`65`

Например, замени его на `40`, чтобы машины ехали медленнее.

### Изменить количество колонок

Найди:

`const COLS = 5;`

Например:

`const COLS = 7;`

### Поменять персонажа

Сейчас персонажи рисуются emoji:

`🐱`
`🐸`

Их можно заменить другими emoji прямо в коде.

## Как запускать игру через локальный сервер

Обычно это не требуется, но это полезный способ запуска.

Открой приложение Terminal, перейди в папку игры:

`cd путь/до/crossy_pets`

После этого выполни:

`python3 -m http.server 8000`

Затем в браузере открой:

`http://localhost:8000`

Чтобы остановить сервер, вернись в Terminal и нажми:

`Control + C`

## Как понять ошибку

Если после правки что-то перестало работать:

1. Не меняй сразу много мест.
2. Посмотри JavaScript Console.
3. Найди первую красную ошибку.
4. Посмотри номер строки.
5. Верни последнее изменение.
6. Обнови страницу.
7. Если снова работает — проблема была именно в последнем изменении.

Главное правило для начала: меняй одну маленькую вещь за раз.
