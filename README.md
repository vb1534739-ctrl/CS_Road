# Crossy Pets 3D

Самодостаточная браузерная версия игры без внешних библиотек.

## Публикация

В корне репозитория должны лежать:

- `index.html`
- `README.md`

GitHub Pages:
- Branch: `main`
- Folder: `/ (root)`

После изменений:

```bash
git add .
git commit -m "Update game"
git push
```

## Управление

Desktop:
- ↑ / Space — вперед
- ↓ — назад
- ← → — в стороны

Mobile:
- тап — вперед
- свайпы — движение
- экранные стрелки — движение

Если персонаж стоит на бревне, он движется вместе с бревном.
