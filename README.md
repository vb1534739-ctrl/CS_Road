# Crossy Pets 3D

Настоящая WebGL-версия без внешних библиотек. Весь код игры находится в `index.html`.

## Публикация на GitHub Pages

В корне репозитория должны лежать:

- `index.html`
- `README.md`

После замены файла:

```bash
git add .
git commit -m "True WebGL 3D version"
git push
```

GitHub Pages: `main` + `/ (root)`.

## Управление

Desktop: стрелки / WASD / Space.
Mobile: тап вперед, свайпы и экранные стрелки.

Персонаж, вставший на бревно, движется вместе с ним.
